# **CJRM** | Etapa 15 - Banco de Dados

## Introdução ao Firebase
Firebase é uma plataforma de serviços back-end do google, ou seja, uma BAAS (Back-end As A Service). Sendo assim, ele oferece uma série de funções para a aplicação além do banco de dados, que neste caso é um banco não relacional, como autenticação de usuário, analytics, testes a/b, relatórios de crashing, etc.
