## Uma introdução ao Bootstrap

  O bootstrap é uma biblioteca de componentes de front-end, o que possibilita a reutilização de componentes pré definidos na interface do usuário, facilitando o design do projeto. É possível consultar as classes e presets que são utilizáveis através da aba Utilities na documentação.

## Função setTimeout()

  Tem como principal utilidade predefinir um tempo determinado em milisegundos para executar uma dada função.

  ```js
  setTimeout(() => {
    console.log('Esta função demorou 1 segundo para ser executada')
  }, 1000)
  ```

## Função setInterval()

  Tem como objetivo predefinir um tempo em milisegundos, que será o intervalo entre cada execução da função que é passada por argumento.

  ```js
  setInterval(() => {
    console.log('1 segundo se passou')
  }, 1000)
  ```
